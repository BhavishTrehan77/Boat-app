PRD — Product Requirements Document

The Boat Warranty & Repair Management System is a web application designed to allow customers to check their Boat product warranty and repair history using a unique serial number. Users can create an account, log in securely, search for a product using its serial number, view product details, check warranty expiry, access warranty documents, and view paginated repair history. Admin users have additional permissions to manage products, repair records, and warranty documents. The main functional requirements include user signup and login, JWT-based authentication, password hashing using bcrypt, product lookup through serial number, warranty status checking, repair history management, pagination, warranty PDF upload, and role-based access control. The system should also provide proper validation, error handling, secure authentication, and reliable database operations.
