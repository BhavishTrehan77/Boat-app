HLD — High Level Design

The application follows a layered full-stack architecture using Next.js for the application and API layer, Prisma as the ORM, and MySQL as the relational database. The client sends HTTP requests to Next.js API route handlers, which perform authentication and request validation before passing the request to the appropriate controller or service layer. The service layer contains the main business logic and communicates with the MySQL database through Prisma. The main entities in the system are User, Product, WarrantyDocument, and RepairHistory. A User can have multiple Products, a Product can have multiple WarrantyDocuments, and a Product can have multiple RepairHistory records. JWT is used for authentication, bcrypt is used for password hashing, Zod is used for request validation, and role-based authorization ensures that only ADMIN users can perform administrative operations such as product management, repair management, and warranty document management. The application also uses Docker for containerization and Jest for backend testing.
